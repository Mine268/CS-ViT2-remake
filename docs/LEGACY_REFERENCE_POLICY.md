# 老代码参考口径

当 remake 仓库中的某些实现细节、行为边界或历史设计原因不明确时，参考老仓库：

- 老仓库路径：`/data_1/renkaiwen/CS-ViT2`

参考顺序如下：

1. 以 remake 仓库当前代码、配置和文档为第一优先级。
2. 如果 remake 中没有写清楚，或实现意图无法从当前仓库直接判断，再回看老仓库对应实现。
3. 如果老仓库与 remake 的显式设计目标冲突，以 remake 的精简主线为准，不回退到旧分支兼容逻辑。

适合参考老代码的场景：

- 某个张量字段的历史语义不清楚
- 数据预处理或导出格式的约定没有写全
- 模型某层的输入输出行为需要追溯
- 非有限值停机、可视化、测试脚本等辅助流程的细节需要补齐

不应直接继承老代码的内容：

- `norm_by_hand`
- `softargmax3d`
- `xy_rootz_multibin`
- `depth_bins`
- `COCO-WholeBody`
- `AIM`

结论：

- 老仓库是 remake 的参考来源，不是兼容目标。
